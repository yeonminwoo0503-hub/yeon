⚡ 실시간 DB 연결

Firebase Realtime Database 주소를 넣으면 회의실 대화와 안건 보드가 3초마다 자동 동기화됩니다. 주소를 비우면 이 브라우저 저장소(localStorage)만으로 동작합니다.

현재: 로컬 모드

REST JSON 형식 (부이 등 외부 AI·스크립트 연결용) 
GET  {BASE}/messages.json
GET  {BASE}/tasks.json

PUT  {BASE}/messages/{id}.json
{ "id": "m-1732712345", "author": "부이",
  "room": "meeting", "text": "실행 범위 의견 3가지 정리했습니다",
  "ts": 1732712345000 }

PUT  {BASE}/tasks/{id}.json
{ "id": "t1", "title": "실행 범위", "owner": "부이",
  "status": "의논중", "desc": "웹 조회·예약·구매·전화 대행 범위" }

author: minu | karmi | bui
room:   meeting | work | notion | lounge
status: 의논중 | 진행중 | 완료

Firebase 콘솔 → Realtime Database → 규칙에서 .read·.write 권한을 열어야 브라우저에서 바로 읽고 쓸 수 있습니다. 공개 페이지라면 규칙에 만료일이나 인증 조건을 두는 편이 안전합니다.
